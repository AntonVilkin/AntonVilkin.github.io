Privacy policy – Anton digest

Last updated: 22/10/2026

Who uses it

Anton digest is a personal tool. Its only user is Anton Vilkin, using his own Google account. It is not offered to anyone else.

What Google data it reads

  • Gmail (read-only, gmail.readonly): sender, subject, date, labels and a short preview of recent inbox emails.
  • Google Calendar (read-only, calendar.readonly): titles and times of events on Anton's primary calendar.

The tool cannot send, delete or change emails or events.

How the data is used

The data is only used to make a short private summary for Anton: new messages, things that need a reply, and whether planned meetings are in his calendar. It is not used for advertising, profiling or training AI models.

Where the data is stored

The summary and the access token are stored only on Anton's own computer, in files that only his user account can read. Nothing is stored on this website. The summary is replaced on each run.

Sharing

Google user data is never sold or shared with anyone. It is never sent to any server other than Google's own APIs and Anton's own computer.

Limited use

Anton digest's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

How to stop access

Access can be removed at any time at myaccount.google.com/permissions. The local token file is then deleted.
